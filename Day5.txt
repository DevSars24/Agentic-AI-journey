## 🤖 2. LLM vs LLM (AI Battle Concept)

### 💡 Definition:

Two or more LLMs interacting with each other to solve or debate a problem.

---

### 🔄 Flow:

```text
LLM 1 → Prompt
   ↓
LLM 2 → Response
   ↓
LLM 1 → Counter response
   ↓
Loop continues
```

---

### 🔥 Use Cases:

* Debate systems
* Evaluation and benchmarking
* Testing reasoning ability

---

### ⚠️ Important Insight:

LLMs can make mistakes (hallucinate).

Example:

* Incorrect comparison like 9.11 vs 9.8

👉 Always validate outputs in production systems.

---

## 🧠 3. Multi-Agent Systems (Core Concept)

### 💡 Definition:

A system where **multiple specialized agents collaborate** to solve a problem.

---

### 🔥 Example:

* Spanish Agent → responds only in Spanish
* English Agent → responds only in English
* Triage Agent → decides which agent should respond

---

### 🔄 Flow:

```text
User Input
   ↓
Triage Agent
   ↓
Select appropriate agent
   ↓
Final Response
```

---

### 🧠 Key Concept: Handoff

Agents can pass tasks to each other.

```python
handoffs = [spanish_agent, english_agent]
```

---

### 🔥 Interview Answer:

> A multi-agent system consists of multiple specialized agents that collaborate and transfer tasks using handoffs.

---

## ⚙️ 4. Agent SDK

### 💡 Definition:

A framework used to **create, manage, and run AI agents programmatically**.

---

### Example:

```python
english_agent = Agent(
  name="English agent",
  instructions="You only speak English"
)
```

---

### 🔑 Key Components:

* Agent
* Instructions
* Runner
* Input
* Output

---

### ▶️ Runner:

```python
result = await Runner.run(triage_agent, input="Hola...")
```

👉 Executes the agent workflow.

---

## 🧠 5. Role of Instructions

Instructions define the **behavior and personality** of an agent.

---

### Examples:

* “You only speak English”
* “Always respond formally”

---

### 🔥 Interview Point:

> Instructions act as system-level prompts that guide agent behavior.

---

## 🔌 6. Model Context Protocol (MCP)

### 💡 Definition:

> MCP is a standard protocol that allows AI models to interact with external tools and resources.

---

### 💡 Simple Analogy:

👉 MCP is like a **USB interface for AI systems**

---

### ⚙️ Example Code:

```js
server.resource(
  "greeting",
  new ResourceTemplate("greeting://{name}")
);
```

---

### 🔄 Flow:

```text
User → LLM
   ↓
LLM → MCP Server
   ↓
MCP → Fetch resource/tool
   ↓
LLM → Final response
```

---

### 🔥 Why MCP?

* Standardized integration
* Easier tool connection
* Scalable architecture

---

### 🧠 Interview Answer:

> MCP enables standardized communication between AI models and external systems.

---
