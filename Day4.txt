# ⚙️ 2. Workflow Architecture (n8n / Automation Tools)

## 🔄 Flow:

```text
When chat message received
        ↓
AI Agent (Brain)
        ↓
Tools (Execution)
        ↓
Action (Post Tweet / API call)
```

---

## 🧩 Components Breakdown

### 🟢 1. Trigger Node

👉 `When chat message received`

* Starts workflow
* Input = user message

---

### 🧠 2. AI Agent Node

👉 Core brain of system

Connected with:

* Chat Model (LLM)
* Memory
* Tools

---

### 🔥 3. Chat Model

👉 Example: OpenAI model

* Generates responses
* Decides actions

---

### 🧠 4. Memory (VERY IMPORTANT)

👉 Window Buffer Memory

### Purpose:

* Stores conversation history
* Maintains context

### Example:

User: "Write tweet"
→ remembers previous context

---

### 🧰 5. Tools

👉 Example: Code Tool

* Executes logic
* Can call APIs
* Can process data

---

### 🚀 6. Final Action

👉 Example:

* Post Tweet on X (Twitter)

---
