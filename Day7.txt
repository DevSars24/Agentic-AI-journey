## 🧠 1. What is an Agent?

👉 **Definition:**
An **Agent = LLM + Tools + Instructions + Execution Layer**

> Instead of just answering, an agent can **take actions**.

### 💡 Formula:

```
Agent = LLM + Tools + Instructions + Guardrails + Orchestration
```

### 🔥 Key Idea:

* LLM alone → answers questions
* Agent → **does tasks**

---

## ⚡ 2. LLM API vs Agent

### 🟡 Normal LLM Call:

* Input → Output (text only)
* Example:

  ```
  "What is weather in Patiala?"
  ```

  → LLM guesses (may hallucinate ❌)

---

### 🟢 Agent-Based Approach:

* Uses **tools + real data**
* Example flow:

  ```
  User → Agent → Weather API → Response
  ```

👉 **Result:**

* Accurate ✅
* Real-time ✅
* Actionable ✅

---

## 🛠️ 3. Tools in Agents (VERY IMPORTANT 🔥)

### 👉 What is a Tool?

A function that an agent can call to perform real-world tasks.

---

### 📌 Example: Weather Tool

```js
const getWeatherTool = tool({
  name: 'get_weather',
  description: 'returns weather info',
  execute: async ({ city }) => {
    // API call
  }
});
```

---

### 🧠 Key Concepts:

* Tool = external capability
* LLM decides **when to call tool**
* Tool returns structured data

---

### 🎯 Interview Point:

> "Tools convert LLM from passive responder to active problem solver"

---

## 📦 4. Structured Output (Zod)

👉 Problem:
LLMs return messy text ❌

👉 Solution:
Use schema validation (Zod)

---

### 📌 Example:

```js
const schema = z.object({
  city: z.string(),
  degree_c: z.number(),
  condition: z.string()
});
```

---

### 🔥 Benefits:

* Clean JSON output ✅
* Type safety ✅
* No parsing headache ✅

---

### 🎯 Interview Line:

> "Structured outputs ensure reliability and production-grade responses"

---

## 🤖 5. Creating Your First Agent

```js
const helloAgent = new Agent({
  name: 'Hello Agent',
  instructions: 'Always say hello world'
});
```

---

### ▶️ Running Agent:

```js
run(helloAgent, "Hey my name is Piyush")
  .then(result => console.log(result.finalOutput));
```

---

### 🧠 Key Points:

* `instructions` = brain/personality
* `run()` = execution engine
* `finalOutput` = final response
